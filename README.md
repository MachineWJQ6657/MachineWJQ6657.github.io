# Portfolio Studio

一个以英文博客与个人介绍为核心、带私有编辑台和云端持久化的个人网站模板。源码保存在 GitHub，运行环境为 Cloudflare Workers + D1。

## 已包含

- 响应式个人主页：自我介绍、博客文章、项目、经历与联系方式
- 独立文章阅读页：支持段落与二级标题，并随后台内容同步
- `/studio` 私有编辑台：文章管理、所见即所得编辑与自动保存
- 云端 D1 数据库：内容刷新、换设备后仍然保留
- 近实时同步：公开页面会自动拉取最新已发布内容
- 主题定制：颜色、圆角和版块显隐
- 高级 JSON：完整备份、迁移与批量编辑
- 管理员密码登录：密码只保存在 Cloudflare Secret，不进入 GitHub

## 本地开发

项目使用 Vinext 和 Cloudflare Workers。安装依赖后运行 `npm run dev`；D1 数据库会在首次访问时自动初始化。

正式发布前需在 Cloudflare 中设置 `ADMIN_PASSWORD` Secret，然后运行数据库迁移与部署脚本。`wrangler.jsonc` 已包含 Worker、D1 和根域名配置。

## 自定义流程

1. 打开 `/studio`。
2. 修改文案、项目、经历和视觉主题。
3. 更改会自动保存；打开的主页会在数秒内同步。
4. 编辑台使用 Cloudflare 中配置的管理员密码登录；公开页面不需要登录。
