# Portfolio Studio

一个以英文博客与个人介绍为核心、带私有编辑台和云端持久化的个人网站模板。

## 已包含

- 响应式个人主页：自我介绍、博客文章、项目、经历与联系方式
- 独立文章阅读页：支持段落与二级标题，并随后台内容同步
- `/studio` 私有编辑台：文章管理、所见即所得编辑与自动保存
- 云端 D1 数据库：内容刷新、换设备后仍然保留
- 近实时同步：公开页面会自动拉取最新已发布内容
- 主题定制：颜色、圆角和版块显隐
- 高级 JSON：完整备份、迁移与批量编辑
- 首位管理员锁定：首次登录并保存的用户成为唯一站点管理员

## 本地开发

项目使用 Sites 的 Vinext 运行环境。安装依赖后启动开发服务即可；数据库会在首次访问时自动初始化，部署时也会应用 `drizzle/` 中的迁移。

## 自定义流程

1. 打开 `/studio`。
2. 修改文案、项目、经历和视觉主题。
3. 更改会自动保存；打开的主页会在数秒内同步。
4. 首次部署建议保持私有，进入编辑台保存一次以锁定管理员，再按需开放公开访问。
